# Azure Development Examples

This directory contains example configurations and templates for Azure development.

## Contents

- `arm-template.json` - Azure Resource Manager template for basic web app deployment
- `docker-compose.yml` - Multi-container development environment
- `azure-pipelines.yml` - Azure DevOps pipeline configuration
- `github-actions.yml` - GitHub Actions workflow for Azure deployment
- `terraform/` - Infrastructure as Code using Terraform
- `bicep/` - Modern ARM template alternative using Bicep

## Quick Start

1. Choose your deployment method (ARM, Terraform, or Bicep)
2. Update the configuration files with your specific values
3. Deploy using Azure CLI, Azure DevOps, or GitHub Actions

## Prerequisites

- Azure subscription
- Azure CLI installed and configured
- Appropriate permissions for creating resources
